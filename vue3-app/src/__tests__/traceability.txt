TRACEABILITY MATRIX
===================
Maps every business rule (business_rules.txt), application flow
(application_flows.txt), UI behaviour test (ui_tests_vue2.md) and visual
regression screenshot pair (before_migration/ <-> after_migration/final-validation/)
to the test cases that verify it.

Test suites
-----------
U  = Vitest unit/integration  (src/__tests__/*.spec.js, 77 tests)
E  = Playwright E2E           (e2e/**/*.spec.js, 80 tests)
B  = Playwright UI behaviour  (e2e/ui-behavior/cases.mjs replayed by
                               e2e/ui-behavior/ui-behavior.spec.js and
                               scripts/run-ui-tests.mjs, 34 cases)
V  = pixelmatch visual score  (scripts/compare.mjs -> visual_scores.json)
